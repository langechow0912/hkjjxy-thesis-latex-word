
范文类创建模板
开发中
POST
/api/public/template-editor/analyze-and-create/stream
调试
费用：5块一次
鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
上传一份已经正确排版的 DOCX 样例文档。上游通过锚点分析提取排版规则，并直接创建模板。
请求
POST /api/public/template-editor/analyze-and-create/stream
Content-Type: multipart/form-data
Form 参数
参数	类型	必填	说明
file	file	是	已正确排版的样例 DOCX
school_name	string	否	学校或模板展示名称
owner_id	string	是	调用方业务用户或租户 ID
请求示例
curl -N -X POST \
  'https://apihub.ycjg.top/api/public/template-editor/analyze-and-create/stream' \
  -H 'Authorization: Bearer <API_KEY>' \
  -F 'file=@formatted-example.docx' \
  -F 'school_name=示例大学' \
  -F 'owner_id=school-123'
complete 事件
event: complete
data: {"status":"SUCCEEDED","templateId":"20260815d674b65e358ea1cf2ea09cdc","templateName":"示例大学_x1Yz9","schemaVersion":"2026-08-14.1:user:opaque:819b565f44","ownerId":"apihub:42:school-123","editorUrl":"https://apihub.ycjg.top/template-editor?templateId=20260815d674b65e358ea1cf2ea09cdc","message":"模板已创建，可继续调整并保存"}
随后 APIHub 追加计费事件：
event: billing
data: {"success":true,"cost":3.0,"remaining_balance":97.0,"usage_count":1}
计费规则
调用前检查余额，不足返回 402，不会调用上游。
只有收到上游 complete 事件后才扣费。
上游返回 error 或客户端提前断开时不扣费。
