
格式检查+生成带标注的交互HTML报告
开发中
POST
/api/public/format-check/check/report
调试
鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
检查论文 DOCX 是否符合指定模板，并生成包含违规标注的交互 HTML 报告。
违规段落会按严重级别着色，报告右侧的问题列表可与文档热区联动。
请求
POST /api/public/format-check/check/report
Content-Type: multipart/form-data
Form 参数
参数	类型	必填	说明
file	file	是	待检查的论文 DOCX 文件
template_id	string	是	模板列表返回的 templateId
请求示例
curl -X POST 'https://apihub.ycjg.top/api/public/format-check/check/report' \
  -H 'Authorization: Bearer <API_KEY>' \
  -F 'file=@paper.docx' \
  -F 'template_id=_default_arts' \
  -F 'owner_id=school-123'
成功响应
状态码：200 OK
{
  "summary": {},
  "violations": [],
  "fileId": "report.html",
  "previewUrl": "https://example.com/report/preview",
  "downloadUrl": "https://example.com/report/download",
  "stats": {}
}
费用：5块一次
错误响应
状态码	说明
400	参数为空、文件不合法或文件类型不支持
401	API Key 缺失或无效
404	模板不存在，或不属于当前 owner 空间
422	缺少必填字段
502	上游格式检查服务异常
