file	必填	文件	要检测的文档。仅支持 .doc/.docx/.txt, 不能为空，≤20MB, 字数 0~50000

title	选填	字符串	文档标题，透传给检测服务
author	选填	字符串	作者，透传给检测服务
brand_title	选填	字符串	品牌主标题 (报告页眉 / 水印类的展示用), 透传
brand_subtitle	选填	字符串	品牌副标题，透传
