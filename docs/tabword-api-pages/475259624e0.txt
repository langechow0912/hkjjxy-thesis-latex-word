Header参数（二选一即可）
参数名	类型	是否必填	说明
Authorization	String	否	API 密钥
X-API-Key	String	否	API 密钥
Body参数
参数名	类型	是否必填	说明
file	file	是	待改写的word文档
preset_zh	String	是	中文改写模型
preset_en	String	是	英文改写模型
callback_url	String	否	回调地址，文档处理完成后会对这个url发送处理好的数据
generate_diff	boolean	是	是否生成对比文档
generate_diff
如果为true的话则返回的字段里面的diff_url不会为null，而是为一个下载链接，下载的word文档为改写后的word文档，且将改写的具体文本标注为红色
参数名	说明
original_ai_rate	原始AI率
rewritten_ai_rate	改写后AI率
reduction	减少了多少
ai_detection_success	AI率检测是否成功
