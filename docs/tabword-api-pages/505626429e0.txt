/api/public/template-editor/templates/{template_id}
调试
鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
根据 template_id 删除当前 owner 空间中的模板。删除操作不可恢复。
内置默认模板和系统模板不可删除。
请求
DELETE /api/public/template-editor/templates/{template_id}?owner_id={owner_id}
参数
参数	位置	类型	必填	说明
template_id	Path	string	是	模板列表返回的 templateId
请求示例
curl -X DELETE \
  'https://apihub.ycjg.top/api/public/template-editor/templates/20260815d674b65e358ea1cf2ea09cdc?owner_id=school-123' \
  -H 'Authorization: Bearer <API_KEY>'
成功响应
状态码：200 OK
{
  "message": "Deleted template 示例模板."
}
错误响应
状态码	说明
400	owner_id 为空或无效
401	API Key 缺失或无效
403	内置默认模板或系统模板不可删除
404	模板不存在，或不属于当前 owner 空间
422	缺少必填参数
