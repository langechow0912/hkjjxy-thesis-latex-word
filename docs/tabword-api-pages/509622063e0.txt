
提交异步格式检测报告任务
开发中
POST
/api/public/format-check/jobs
调试
费用：5块一次
鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
提交论文格式检查任务并立即返回 jobId。格式检查和 HTML 报告生成在上游后台执行。
请求
POST /api/public/format-check/jobs
Content-Type: multipart/form-data
Form 参数
参数	类型	必填	说明
file	file	是	待检查的论文 DOCX 文件
template_id	string	是	模板列表返回的 templateId
owner_id	string	是	调用方业务用户或租户 ID
请求示例
curl -X POST 'https://apihub.ycjg.top/api/public/format-check/jobs' \
  -H 'Authorization: Bearer <API_KEY>' \
  -F 'file=@paper.docx' \
  -F 'template_id=_default_arts' \
  -F 'owner_id=school-123'
成功响应
状态码：202 Accepted
{
  "jobId": "format-check-job-id",
  "status": "PENDING",
  "message": "任务已提交"
}
错误响应
状态码	说明
400	参数为空、文件不合法或文件类型不支持
401	API Key 缺失或无效
404	模板不存在，或不属于当前 owner 空间
422	缺少必填字段
502	上游异步任务提交失败
503	APIHub Redis 异步任务状态服务不可用
