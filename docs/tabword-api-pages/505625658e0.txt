
说明类创建模版
开发中
POST
/api/public/template-editor/instruction-analyze-and-create/stream
调试
费用：5块一次
鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
上传学校论文格式说明文档，由 AI 并行解析封面、声明页、目录、标题层级、正文和参考文献等规则并创建模板。
该接口以文档中的文字规范为依据，说明文档自身的排版不会直接作为目标样式。
请求
POST /api/public/template-editor/instruction-analyze-and-create/stream
Content-Type: multipart/form-data
Form 参数
参数	类型	必填	说明
file	file	是	格式说明文档，支持 PDF、DOC、DOCX
school_name	string	否	学校名称；不传时由文档内容推荐
owner_id	string	是	调用方业务用户或租户 ID
请求示例
curl -N -X POST \
  'https://apihub.ycjg.top/api/public/template-editor/instruction-analyze-and-create/stream' \
  -H 'Authorization: Bearer <API_KEY>' \
  -F 'file=@format-instructions.pdf' \
  -F 'school_name=示例大学' \
  -F 'owner_id=school-123'
complete 事件
返回结构与“范文类创建模板”一致：
event: complete
data: {"status":"SUCCEEDED","templateId":"20260815d674b65e358ea1cf2ea09cdc","templateName":"示例大学_x1Yz9","schemaVersion":"2026-08-14.1:user:opaque:819b565f44","ownerId":"apihub:42:school-123","editorUrl":"https://apihub.ycjg.top/template-editor?templateId=20260815d674b65e358ea1cf2ea09cdc","message":"模板已创建，可继续调整并保存"}
成功后 APIHub 追加 billing 事件，计费规则与范文类创建模板一致。
