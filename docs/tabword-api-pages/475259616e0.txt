/api/v2/paraphrase/stream
调试
接口地址：POST /api/v2/paraphrase/stream
接口名称：段落改写（流式模式）
功能描述：以 SSE 流式方式返回改写进度、统计信息和计费结果，适合实时渲染场景
请求头
参数名	必填	类型	说明
Authorization	是	string	API 密钥。支持两种格式：sk-xxx 或 Bearer sk-xxx
Content-Type	是	string	固定为 application/json
Body参数
参数名	类型	是否必填	说明
preset	String	是	改写预设 可以从GET /api/v2/presets 接口获取
text	String	是	待改写的字段
请求示例
{
  "text": "这是一个用于测试流式改写接口的短文本。",
  "preset": "aigcmove_tp_s_2"
}
响应格式
响应类型：text/event-stream
返回方式：SSE 持续推送
编码格式：每条消息由 event 和 data 组成
响应示例
event: start
data: {"total": 2, "mode": "standard"}

event: progress
data: {"index": 0, "original": "...", "rewritten": "...", "status": "success"}

event: stats
data: {"char_stats": {...}, "total_time": 2.64}

event: billing
data: {"success": true, "cost": 0.25, "remaining_balance": 99.75, "char_count": 500}

event: done
data: {"message": "成功处理 2 个段落", "request_id": "xxx", "total_time": 2.64}
事件类型说明
事件名	说明
start	开始处理，返回总段落数、模式等基础信息
progress	处理进度事件，可能返回多次，每次对应一个段落
stats	统计信息，如字数统计、处理耗时等
billing	计费结果，包含本次费用、剩余余额、字符数
done	全部处理完成
error	处理失败或业务异常
字段说明
progress 事件常见字段
字段名	类型	说明
index	int	当前段落索引，从 0 开始
original	string	原始文本
rewritten	string	改写后的文本
status	string	当前段落处理状态，如 success
billing 事件常见字段
字段名	类型	说明
success	bool	是否计费成功
cost	number	本次扣费金额
remaining_balance	number	扣费后的剩余余额
char_count	int	本次计费字符数或单位数
done 事件常见字段
字段名	类型	说明
message	string	完成提示
request_id	string	请求唯一标识
total_time	number	总耗时，单位秒
重要说明
返回方式为流式输出，不是普通 JSON 一次性返回
progress 事件可能返回多次
billing 事件通常在处理完成后返回
如果发生错误，会返回 error 事件
适合前端实时展示改写进度、逐段渲染结果
前端调用说明
这是 POST 流式接口
不能直接使用 EventSource
建议使用 fetch + ReadableStream 读取返回内容
