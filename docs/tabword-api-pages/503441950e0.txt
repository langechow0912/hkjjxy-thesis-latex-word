鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
Query 参数
参数	类型	必填	说明
owner_id	string	是	调用方业务用户或租户 ID
请求示例
curl 'https://apihub.ycjg.top/api/templates?owner_id=school-123' \
  -H 'Authorization: Bearer <API_KEY>'

错误响应
状态码	说明
400	owner_id 为空或映射后超过 64 个字符
401	API Key 缺失或无效
422	缺少 owner_id 参数
502	获取上游模板列表失败
