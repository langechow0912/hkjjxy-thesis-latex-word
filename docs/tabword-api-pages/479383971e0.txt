请求头 (Headers)
参数名	必填	类型	说明
Authorization	是	string	API密钥，支持两种格式：1. 直接填写密钥值 2. Bearer {密钥值}
说明
接口会返回当前账户未分配的余额以及请求头对应密钥的余额
返回示例：
{
    "account": {
        "balance": xxx
    },
    "key": {
        "api_key": "sk-***xxxxxx",
        "name": "xxxx",
        "remaining_balance": xxx
    }
}
如果"remaining_balance": null证明该密钥未分配额度，使用的是账户未分配余额
