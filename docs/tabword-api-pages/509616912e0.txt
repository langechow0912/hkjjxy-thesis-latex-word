POST
/api/public/format/jobs
调试
费用：5块一次
鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
上传论文 DOCX 或 PDF 并指定模板，立即返回 jobId，上游在后台完成内容提取与模板排版。
请求
POST /api/public/format/jobs
Content-Type: multipart/form-data
Form 参数
参数	类型	必填	说明
file	file	是	待排版论文，支持 DOCX、PDF
template_id	string	是	模板列表返回的 templateId
请求示例
curl -X POST 'https://apihub.ycjg.top/api/public/format/jobs' \
  -H 'Authorization: Bearer <API_KEY>' \
  -F 'file=@paper.docx' \
  -F 'template_id=_default_arts' \
  -F 'owner_id=school-123'
成功响应
状态码：202 Accepted
{
  "jobId": "format-job-id",
  "status": "PENDING"
}
计费说明
提交时检查余额，但不立即扣费。
余额不足返回 402，不会提交上游任务。
查询任务结果为 SUCCEEDED 时扣费。
RUNNING 或 FAILED 不扣费。
错误响应
状态码	说明
400	参数为空、文件不合法或文件类型不支持
401	API Key 缺失或无效
402	余额不足
404	模板不存在，或不属于当前 owner 空间
422	缺少必填字段
502	上游异步任务提交失败
503	APIHub Redis 异步任务状态服务不可用
