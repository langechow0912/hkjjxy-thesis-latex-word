
获取模板编辑器链接
开发中
GET
/api/public/template-editor/templates/{template_id}/editor-url
调试
鉴权
所有接口均支持以下任意一种鉴权方式：
Authorization: Bearer <API_KEY>
或：
X-API-Key: <API_KEY>
根据 template_id 返回可视化模板编辑器链接，调用方可以引导用户打开链接调整模板。
请求
GET /api/public/template-editor/templates/{template_id}/editor-url?owner_id={owner_id}
参数
参数	位置	类型	必填	说明
template_id	Path	string	是	模板列表返回的 templateId
请求示例
curl \
  'https://apihub.ycjg.top/api/public/template-editor/templates/20260815d674b65e358ea1cf2ea09cdc/editor-url?owner_id=school-123' \
  -H 'Authorization: Bearer <API_KEY>'
成功响应
状态码：200 OK
{
  "templateId": "20260815d674b65e358ea1cf2ea09cdc",
  "templateName": "示例大学_x1Yz9",
  "editorUrl": "https://apihub.ycjg.top/template-editor?templateId=20260815d674b65e358ea1cf2ea09cdc"
}
错误响应
状态码	说明
400	owner_id 为空或无效
401	API Key 缺失或无效
404	模板不存在，或不属于当前 owner 空间
422	缺少必填参数
