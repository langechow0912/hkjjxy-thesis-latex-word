# 踩坑清单 —— 海口经济学院这一轮总结出来的

按「症状 → 原因 → 修法」记。前 6 条是用户肉眼能看出来的错误，后面是隐藏缺陷和工程坑。
做下一所学校时，先照着文末的**验收清单**过一遍，能省掉大半返工。

---

## A. 会被用户一眼看穿的错误

### A1. 每页顶部出现重复的章节名（斜体）
- **症状**：PDF 每页页眉印着当前章节标题，看着像「重复的斜体标题」。
- **原因**：`ctexart` 默认 `\pagestyle{headings}`，页眉自动放章节名、页码在右上。
- **修法**：格式包里显式 `\pagestyle{plain}` → 无页眉、页码页脚居中。
- **注意**：ctex 的 headings 页眉是**文档类默认行为**，不是你代码里写错了，
  但用户会当成排版错误。新学校第一件事就是确认 pagestyle。

### A2. 引言没有另起一页
- **症状**：摘要和引言连在一起，学校要求引言另起页。
- **原因**：转换脚本的 SKIP 黑名单里写了 `\\newpage`，把它当「忽略」处理了；
  空行也会触发 flush，但分页动作被吞掉。
- **修法**：`\newpage` 是**动作**不是噪音，从 SKIP 里拿出来，转成 `WD_BREAK.PAGE`。
- **教训**：按「忽略 / 动作 / 内容」三类分命令，别只做黑名单。
  新增任何 tex 命令时都要先问：它是动作还是噪音？

### A3. PDF 封面页和声明页错乱
- **症状**：封面内容被挤压、声明页内容溢到封面上。
- **原因**：拿**源稿 docx** 直接 LibreOffice 转 PDF 取前 2 页。源稿里有文本框、
  复杂表格，LibreOffice 渲染位置与 Word 不一致。
- **修法**：统一口径 —— 先生成我们自己的 docx，再把**它的**前 2 页转 PDF 嵌进 LaTeX。
  这样 PDF 与 Word 的封面/声明完全一致。
- **延伸**：这条其实定义了整个流水线的顺序 —— Word 必须先于 PDF 产出。

### A4. 目录里出现两个「参考文献」
- **症状**：目录末尾「参考文献」出现两次。
- **原因**：`\unnumsec{参考文献}` 内部已经 `\addcontentsline`，tex 里又写了一次；
  或者 tocloft 自动输出 `\contentsname` 的同时又手写了一遍。
- **修法**：目录标题交给 tocloft，别手写；非 `\section` 的块（摘要/关键词）
  只在 profile 的 `toc.front_entries` 里声明一次。

### A5. 正文里的引用变成乱码（出现 `textbackslash`）
- **症状**：Word 正文出现 `\ref`、`~` 等字面量。
- **原因**：先 resolve 再转义 —— `esc(resolve(x))` 会把注入的反斜杠也转义掉。
- **修法**：顺序反过来 `resolve(esc(x))`：先把**原文**转义干净，再注入 `\ref`/`\cite`。
- **教训**：转义和注入的顺序错一次，就会污染全文，而且很难一眼看出来。

### A6. 表格/图片错位（表跑到别的章节、图题对不上）
- **症状**：表图内容与标题错位若干行。
- **原因**：解析时按「处理后的行号」判定表/图，而预扫描用的是「原始行号」，
  两套索引对不上。
- **修法**：全程只用一套索引（原始段落号），预扫描和正文扫描共用。
- **延伸**：tex 里表题、表体、表注必须打包进**同一个**浮动体（`thesTab` 环境），
  否则三者各自浮动就会分离。

## B. 隐藏缺陷（用户不一定看得出，但确实错了）

### B1. 正文表题编号恒为 0
- **症状**：Word 里表题显示「表　资产负债率分析表」，没有编号。
- **原因**：`seq_caption(doc, tab_total - len(tables), ...)`。
  `tables` 列表只是被 `next()` 迭代，长度**从不变小**，所以这个式子恒为 0。
- **修法**：改用计数器，和图题一样递增。
- **为什么没被发现**：目录里的「表1…表5」是另一套代码生成的，看起来是对的，
  只有正文表题错了 —— 说明校验要**同时查正文和目录**。

### B2. python-docx 读不到 SEQ 域里的编号
- **症状**：`paragraph.text` 里没有表题编号，以为没写进去。
- **原因**：`p.text` 只遍历 `w:r` 子元素；`w:fldSimple` 不是 `w:r`，其中的
  `w:t` 不计入。
- **修法**：校验编号要去解压 `word/document.xml` 看 `<w:fldSimple>` 里的 `<w:t>`。
- **教训**：域代码相关的验证不能靠 python-docx 的高层 API。

### B3. 带圈数字脚注显示成方框
- **症状**：①②③ 显示为缺字形。
- **原因**：Times New Roman 没有这些字形，而它们被判为西文字符。
- **修法**：`\xeCJKDeclareCharClass{CJK}{"2460 -> "2473}` 强制用中文字体渲染。
- **延伸**：任何「中文符号 + 西文字体」的组合都可能踩这个坑。

## C. 工程坑（与学校无关，但每次都会遇到）

### C1. Windows 换行符 `\r\r\n`
- **症状**：正则 `$` 匹配失败、`lines.index("\\begin{document}")` 找不到、
  解析结果整体错位，而且错误现象看起来像「内容错了」。
- **原因**：写文件工具在 Windows 上会产出 `\r\r\n`。
- **修法**：所有入口第一件事 `normalize()` 统一成 `\n`；仓库加 `.gitattributes`
  设 `* text=auto eol=lf`。
- **这是本轮最费时的坑**，因为它伪装成内容错误。

### C2. LibreOffice 单实例
- **症状**：转换命令返回成功，但目标 PDF 不生成（静默失败）。
- **原因**：已有一个 soffice 实例在跑，新请求被丢弃。
- **修法**：每次调用指定独立的 UserInstallation：
  `-env:UserInstallation=file:///C:/temp/lo-<随机>`，再加 3 次重试兜底。

### C3. 格式包副本与真源不同步
- **症状**：改了格式包但 PDF 没变化。
- **修法**：真源只保留 `schools/<id>/format.sty`，论文目录里的同名 .sty 是
  **自动生成的副本**（已 gitignore），由 core 每次构建前同步，不要手改。

### C4. XeLaTeX 只跑一遍
- **症状**：目录空白或显示 `??`。
- **修法**：连跑 3 遍（目录 + 交叉引用需要 aux 收敛）。

## D. 验收清单（新学校做完逐条打勾）

**LaTeX 侧**
- [ ] 页眉已关（不是 `headings`），页码位置/对齐符合要求
- [ ] `\geometry` 页边距与 profile 一致
- [ ] 正文字号、行距、首行缩进正确
- [ ] 三级标题字体字号正确，四级编号不进目录
- [ ] 三线表线宽（顶底 1.5bp / 栏目 0.5bp）
- [ ] 表题在表上方、图题在图下方，均居中
- [ ] 目录标题只出现一次，条目带点线引导、页码右对齐
- [ ] 编译 3 遍后 `??` 为 0 条

**Word 侧**
- [ ] 引言 / 参考文献 / 致谢各自另起一页（验证 `\newpage` 生效）
- [ ] 正文**和**目录里的表题/图题编号都是 1…N 连续（查 XML，别只看 `p.text`）
- [ ] 目录页码与 PDF 实际页码一致
- [ ] 图片数量、表格数量与源稿一致
- [ ] 目录样式（toc 1/2/3）左对齐、无多余缩进

**工程侧**
- [ ] 所有 .tex/.sty/.py/.yaml 都是 LF 换行
- [ ] 论文目录里的 .sty 是副本，真源在 schools/<id>/
- [ ] 一条命令能从 tex 同时出 Word + PDF
