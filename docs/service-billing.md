# 排版、改写与 AIGC 检测收费

管理员在 `/admin/affiliates` 的“服务价格设置”修改价格；需要现有管理员登录。

| 服务 | 默认售价 |
| --- | --- |
| 论文排版 Word 导出 | 沿用 `THESIS_FORMAT_PRICE_CENTS`，未设置时为 29.99 元 / 篇 |
| 文本 AIGC 检测 | 0.99 元 / 次 |
| 文件 AIGC 检测 | 3.99 元 / 次 |
| 改写、降重、降 AI、双降 | 1.00 元 / 千字符 |

改写按非空白字符计数（中文、字母、数字、标点均计入），按实际字符数比例收费，向上取整到分，最低 0.01 元。例如 1001 字符为 1.01 元。Word 改写只接收 `.docx`，服务端从正文 XML 计数；旧版 `.doc` 请先另存为 `.docx`。检测按次收费，不按字数。

价格、报价、处理状态及可恢复的结果存储在 `ALIPAY_ORDER_DB` 指定的现有 SQLite 数据库中，部署时保留该数据卷。默认值只用于尚未设置的价格；后台排版价格优先于环境变量。调价不改变已生成报价或排版支付订单的金额，未付款报价有效期 15 分钟。

## 用户流程

1. 输入正文或上传文件，选择处理模型或检测平台，点击“计价并创建付款订单”。
2. 核对服务、字符数与应付金额，进入支付宝电脑网站收银台付款。
3. 返回原页，点击“我已付款，开始处理”。只有经过现有支付宝验签、商户和金额核验的成功通知才会放行。
4. 文件异步改写提交后查询对应任务；同步和流式结果可通过原订单恢复，无需重新付费或再次调用上游。刷新后保留当前标签页的订单信息；尚未提交的订单需恢复原文、文件和处理选项。

付款绑定具体操作、参数、文件名和文件内容摘要，不能更换论文或模型复用。SQLite 原子更新保证每笔付款只提交一次；异步查询只能查询该订单取得的任务 ID。其他开发接口不对网站用户开放。模型和平台目录仍可免费读取。

服务订单不接受优惠券，现有排版学校券及平台券行为不变；推广归因及付款后佣金结算复用现有支付流程。

## 异常核查

后台“最近服务订单”显示最近 100 条报价 / 支付订单。`failed` 或一直 `processing` 的已付款订单需要人工核查上游及支付宝流水，必要时人工退款；系统不会自动重提，也未接入自动退款接口。浏览器断网或进程退出后，不得直接把订单改回可提交状态，避免上游已受理后重复扣费。

## 验证与部署

离线测试：`python -m unittest discover -s tests -q`。测试使用模拟支付和上游，不产生真实订单或 API 费用。上线仍需在公网环境验证支付宝成功通知和完整业务流程。

更新代码后重新构建并启动原部署栈：`docker compose up -d --build`。已有本地 Python 进程不会自动加载后端改动。无新增密钥或环境变量。
