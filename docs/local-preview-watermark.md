# 海口本地排版 PDF 水印

仅 `core.schoolformat.run` 中学校 ID 为 `hkjjxy` 的本地排版任务，生成带有
“良品论文”浅灰斜向水印的 PDF 预览。每页包含三处水印，含封面。
任务的 PDF 预览及免费 PDF 下载共用该文件，Word 和原始转换 PDF 保持原样。
水印失败时任务报错，不回退提供无水印预览。

沿用 `requirements-local.txt` 已有的 PyMuPDF 和内置中文字体，无新增依赖。
不修改 Dayipaper 云端预览、其他学校或 ALLAPI 仓库。

注意：当前网页入口为全 API 模式，此改动仅用于保留的本地学校排版流程，
不将网页入口切换回本地排版。后续重新接入本地流程时，该流程自动生成带水印预览。
